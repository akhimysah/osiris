# BOOZZO Lab

Commencer par README.md. Le produit est un banc d’essai privé en français. La peluche exploratrice reste immobile. Seul le contenu de l’œil change. Garder le cadrage de la photo, l’iris bleu azur initial, l’écran rond de 6,5 pouces et des voix douces et naturelles.

Distinguer l’aperçu web, l’affichage observé dans l’œil physique et les objectifs théoriques. Chaque validation relève d’une action explicite de l’utilisateur. Conserver les anciennes observations. Le compte rendu est exporté à la demande de l’utilisateur.

Travailler dans les sources ui/ et server.mjs. Le lancement local avec node dev.mjs reconstruit dist/. Tester les changements avec des données locales.
